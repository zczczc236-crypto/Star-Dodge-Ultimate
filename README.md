# 🌟 Star Dodge: Ultimate

HTML5 Canvas와 Web Audio API를 이용해 만든 중독성 있는 회피 게임입니다.

## 🕹️ 게임 방법
- **이동**: 마우스 움직임 또는 화면 터치 드래그
- **목표**: 위에서 떨어지는 빨간 행성들을 피하세요!
- **아이템**: 노란색 별을 먹으면 1회 보호막을 얻습니다.
- **점수**: 적을 피할 때마다 점수가 오르며, 시간이 지날수록 적이 빨라집니다.

## ✨ 주요 특징
- **모바일 완벽 지원**: 반응형 디자인과 터치 컨트롤.
- **다이내믹 사운드**: 별도의 오디오 파일 없이 코드로 생성되는 복고풍 사운드.
- **데이터 저장**: 브라우저 로컬 스토리지를 이용한 최고 점수 기록.
- **시각 효과**: 네온 그래픽과 파티클 폭발 시스템.
